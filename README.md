# California-Housing-Price-Prediction-Model-Comparison
California Housing Price Prediction – Model Comparison

Project Overview

This project predicts housing prices using the California Housing Dataset and compares the performance of multiple machine learning models.

Objectives

- Perform feature scaling and preprocessing
- Train multiple regression models
- Compare model performance
- Evaluate models using RMSE and R² Score
- Visualize Actual vs Predicted values

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

Models Used

1. Linear Regression
2. Ridge Regression
3. Decision Tree Regressor

Evaluation Metrics

- RMSE (Root Mean Squared Error)
- R² Score

Dataset

California Housing Dataset from Scikit-learn.

Results

The models were compared based on RMSE and R² Score, and the best-performing model was selected for prediction.
